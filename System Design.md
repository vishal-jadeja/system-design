# System Design

Hub for [[Vishal]]'s system design track — one design per day, read-first then implement. Feeds the 2026 goals of HLD/LLD and shipping a real product.

## How this works
- **One note per design** in `designs/` — numbered, built from [[Design Template]].
- **One note per concept** in `concepts/` — built from [[Concept Template]]. Stub it the moment a design mentions something you can't explain cold.
- Designs link concepts with `[[wikilinks]]`. Graph view is the progress tracker — a concept with many backlinks is load-bearing; an orphan concept means you learned it and never used it.
- Diagrams are **Mermaid, inline in the note**. No separate HTML/artifact files.
- Implementation code lives in its own repo. The design note links the repo + commit.
